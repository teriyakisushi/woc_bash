# 场景

用户想搞清楚磁盘空间被谁占用了，通常还想知道具体是什么文件。

# 参考命令（作者标注，未经验证）

```bash
d=$(du -sk ./* 2>/dev/null | sort -rn | head -n1 | cut -f2-); du -sh "$d"; ls -la "$d"
```

再往里钻一层：

```bash
du -sh ./* 2>/dev/null | sort -rh | head -n 10
```

# 约定

- `du -sk` 用 KB 排序（纯数字，`sort -rn` 才能正确排）；`du -sh` 只用于展示。
- 直接对 `./*` 展开，不要先 `cd` 进去再算 —— 那会改变 `$PWD` 且需要两条命令。
- `2>/dev/null` 是必须的：权限不足的目录会让 `du` 往 stderr 刷一堆报错，
  而 stderr 会被一起喂回给模型，浪费上下文。

# 不要这样做

- 不要用 `du -sh ./* | sort -rh` 排序后再取第一行：`-h` 产生的是 `140K`/`1.2G`
  这类字符串，`sort` 会得到错误结果（`9K` 会排在 `1.2G` 后面）。
- 不要在 `/` 上跑不带 `-x` 的 `du`：会跨越挂载点扫过所有磁盘，非常慢。
  跨文件系统检查时用 `du -xsh /*`。
- 不要省略 `2>/dev/null`。这是最容易被忽略但每次都会发生的问题。

# 变体

- 只看当前目录不递归：`du -sh ./* | sort -rh | head`
- 找大文件而不是大目录：`find . -type f -size +100M -exec ls -lh {} +`
- 全盘（含挂载点）：`df -h` 先看哪个分区满，再 `du -xsh /挂载点/* | sort -rh | head`
